# Meshmixer enclosure files

These are the two Meshmixer files I still have from this build.

| File | Original filename |
| --- | --- |
| [fbh.mix](fbh.mix) | fbh.mix |
| [fixed-top.mix](fixed-top.mix) | fixed top.mix |

The file contents are unchanged. The space in the second filename was replaced with a hyphen.

Open them in Meshmixer to inspect the designs; they are native project files, not STL exports. I haven't checked which printed revisions they correspond to, so inspect the dimensions and fit before printing.

I went through about ten printed versions to fit the larger screen and electronics, then used hot glue to close the sides. The enclosure also needed ventilation, which I added in the next handheld rather than fixing in this version.
