# Enclosure project files

These are Joseph Dickey's retained Meshmixer project files from the PiGRRL-inspired handheld build.

| Repository file | Original uploaded filename |
| --- | --- |
| [fbh.mix](fbh.mix) | fbh.mix |
| [fixed-top.mix](fixed-top.mix) | fixed top.mix |

Both binary files are preserved byte-for-byte. Only the second filename was normalized to remove its space.

The larger 5-inch display required enclosure changes. Approximately ten printed iterations were made while working through fit problems. The final assembly used hot glue to join the sides.

## Working with the files

Download the files and open them in Meshmixer to inspect the retained meshes and project state. These are native project files, not STL exports.

The internal geometry, units, dimensions, and correspondence to the final printed pieces have not been verified in this repository update. The filenames alone do not establish which final parts or revision each contains. No print-ready claim is made for these historical files.

The enclosure lacked dedicated ventilation and experienced overheating. Any further enclosure development should address both component clearance and airflow; the original thermal issue was not fixed in this version.
